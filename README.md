# weatheremail — 天气邮件推送程序

基于和风天气 API 的命令行天气预警程序。每次运行按**配置的经纬度**获取当地实时天气与次日预报，记录温度，在出现**大范围升降温**或**恶劣天气**时发送 HTML 格式的预警邮件。默认推送北京市，可在设置界面改成任意地点。

- 仅命令行，无图形界面
- 纯 Python 标准库，**无第三方依赖**
- 完全离线运行，数据只从和风天气取，不向任何其它服务器上传

## 安装

```bash
sudo dpkg -i weatheremail_1.0.0_all.deb
```

## 使用

### 首次配置

```bash
weatheremail
```

进入交互式设置界面，按编号选择要修改的项目：

| 编号  | 项目     | 说明                                  |
| --- | ------ | ----------------------------------- |
| 1   | 推送位置   | 地名 + **经纬度**（默认北京市 39.90, 116.41）   |
| 2   | 和风天气   | API KEY、**API Host（必填）**、接口版本       |
| 3   | 邮件发送   | SMTP 服务器、端口、发件人、授权码                 |
| 4   | 收件人    | 收件邮箱列表、邮件主题前缀                       |
| 5   | 恶劣天气预警 | 雨 / 雪 / 冰雹 / 雾霾 / 大风 开关、风力阈值、降水概率门槛 |
| 6   | 温度变化预警 | 总开关、升降阈值（℃）、是否记录历史                  |
| 7   | 发送策略   | 无预警时是否仍发普通简报                        |
| 8   | 立即测试发送 | 保存后真实发一封邮件                          |
| 9   | 仅预览邮件  | 生成 HTML 到本地，不发信                     |
| h   | 查看温度历史 | 最近 14 条记录                           |
| s   | 保存并退出  |                                     |
| q   | 不保存退出  |                                     |

### 设置推送位置

程序按配置的经纬度获取天气，默认是北京市（39.90, 116.41）。
想推送自己所在位置，进入设置界面选 `[1] 推送位置`：

```
  地名（显示在邮件标题，如「北京市朝阳区」）: 上海市黄浦区
  纬度: 31.2304
  经度: 121.4737
```

- **地名**只用于显示（邮件标题、横幅），不会影响取数；
- **经纬度**才是实际取数坐标，纬度范围 `-90 ~ 90`（北纬为正），经度范围 `-180 ~ 180`（东经为正）；
- 经纬度可用地图 App 长按地点取点，或到 <https://www.latlong.net> 等在线工具查询；
- 输入越界或非数字会保留原值并给出提示，不会写坏配置。

保存后写入配置文件的 `location` 字段：

```json
"location": { "name": "上海市黄浦区", "lat": "31.2304", "lon": "121.4737" }
```

### 发送天气邮件

```bash
weatheremail -email
```

### 其它参数

| 参数         | 作用                 |
| ---------- | ------------------ |
| `-email`   | 获取天气并发送天气邮件        |
| `-preview` | 只抓取并生成 HTML 预览，不发信 |
| `-test`    | 发送一封配置测试邮件         |
| `-config`  | 显示当前设置（密钥脱敏）       |
| `-history` | 查看温度历史             |
| `-help`    | 显示帮助               |

### 定时执行

```bash
crontab -e
```

加入一行（每天早上 7 点发送）：

```
0 7 * * * /usr/bin/weatheremail -email
```

## 预警判断逻辑

### 恶劣天气（判断对象：次日预报）

程序同时解析和风天气的天气现象代码与文字描述，识别以下类别：

| 类别      | 触发条件                          | 级别          |
| ------- | ----------------------------- | ----------- |
| 冰雹 / 冻雨 | 代码 404/405/406 或文字含「冰雹/冰粒/冻雨」 | 紧急          |
| 降雪      | 代码 400-410 或文字含「雪」            | 注意          |
| 降雨      | 代码 300-318 或文字含「雨」，且降水概率达到门槛  | 暴雨类为紧急，其余注意 |
| 雾霾 / 沙尘 | 代码 501-515 或文字含「雾/霾/尘」        | 注意          |
| 大风      | 文字含「大风」或风力达到设定风级（默认 6 级）      | ≥8 级为紧急     |

各类别均可在设置中单独关闭。

### 大范围升降温

程序把每次运行的实况温度写入历史记录。下次运行时，将当前温度与
**最近一次历史记录**对比：

```
|当前温度 - 上次记录温度| >= 阈值（默认 5℃）
```

即判定为大范围升温 / 降温。降幅超过阈值 1.6 倍时升级为「紧急」。

> 注意：阈值的含义是「两次运行之间的温差」，不等同于「日温差」。
> 若你每天固定时间运行一次，它就等价于日间温差。

### 邮件触发规则

| 情况                | 邮件类型                       |
| ----------------- | -------------------------- |
| 有恶劣天气或大范围升降温      | **预警邮件**（红色横幅 + 预警卡片 + 建议） |
| 两者都没有             | **普通简报邮件**（蓝色横幅 + 次日天气）    |
| 两者都没有，且关闭了「无预警也发」 | 不发送                        |

## 配置与数据文件

| 路径                                    | 内容                  |
| ------------------------------------- | ------------------- |
| `~/.config/weatheremail/config.json`  | 配置（权限 600）          |
| `~/.config/weatheremail/history.json` | 温度历史                |
| `~/.config/weatheremail/preview/`     | `-preview` 生成的 HTML |

**卸载软件不会删除这些文件**，需手动清理：`rm -rf ~/.config/weatheremail`

### 不落盘密码

如果不想把 SMTP 授权码写进配置文件，可用环境变量覆盖：

```bash
export WEATHEREMAIL_SMTP_PASS='你的授权码'
export WEATHEREMAIL_API_KEY='你的APIKEY'
```

## 和风天气配置说明

需要在设置界面填写**两项**：API KEY 和 API Host。

### API KEY

在 [控制台-项目管理](https://console.qweather.com/project) 点击项目，
在「凭据」区域创建凭据，身份认证方式选 **API KEY**，即可获得。

### API Host（必填）

在 [控制台-设置](https://console.qweather.com/setting) 查看「API Host」，
它是和风天气为**你的账号专属分配**的域名，形如：

```
abcdefg.re.qweatherapi.com
```

**必须填写**，原因：和风天气新版服务按账号隔离域名，使用公共域名
（`api.qweather.com` / `devapi.qweather.com`）会直接返回
`403 Invalid Host`。程序不会内置任何公共域名做兜底，因此该项留空时
无法获取天气数据。

> 该值不硬编码在程序里，只保存在你的本地配置文件中，
> 随时可在设置界面第 [1] 项修改。

### 接口版本

程序同时支持两代接口，由「接口版本」选项控制（默认「自动」）：

|          | 新版 v1                             | 旧版 v7                       |
| -------- | --------------------------------- | --------------------------- |
| 接口       | `/weather/v1/current/{lat}/{lon}` | `/v7/weather/now?location=` |
| API Host | 账号专属域名                            | `devapi.qweather.com`       |
| 认证       | `X-QW-Api-Key` 请求头                | `key` 查询参数                  |

「自动」模式下：Host 指向旧版公共域名则走 v7，否则走新版 v1。

### 常用邮箱 SMTP 参数

| 邮箱     | 服务器                  | 端口  | 加密       | 密码填什么  |
| ------ | -------------------- | --- | -------- | ------ |
| QQ 邮箱  | smtp.qq.com          | 465 | SSL      | 授权码    |
| 163 邮箱 | smtp.163.com         | 465 | SSL      | 授权码    |
| 阿里企业邮  | smtp.qiye.aliyun.com | 465 | SSL      | 登录密码   |
| Gmail  | smtp.gmail.com       | 587 | STARTTLS | 应用专用密码 |

## 退出码

| 码   | 含义     |
| --- | ------ |
| 0   | 成功     |
| 1   | 参数错误   |
| 2   | 配置不完整  |
| 3   | 获取天气失败 |
| 4   | 发送邮件失败 |
